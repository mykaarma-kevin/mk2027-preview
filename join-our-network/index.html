About Our API Partner Program

Once you enroll and receive pre-approval, you’ll be required to review and sign our API agreement and Mutual Non-Disclosure (MNDA) agreement. Our API agreement includes specific language regarding our communications policy - learn more about why this policy is in place here.

A one-time program fee of $750 USD is also required. This fee covers the creation of a sandbox environment, API testing access, support from our API team, and certification of the applications you integrate with myKaarma.

For third-party API partners, there is an additional fee of $75 USD per dealer, per month for API access. This fee is billed to you, the developer—not the dealership.

Monthly API fees are waived for dealership-built solutions that are used internally by active myKaarma customers.

All developers must name an existing myKaarma customer who will act as your alpha dealership and a designated contact at that dealership before joining the partner program.

Questions about our API Partner program or questions about Strategic and Revenue Partner consideration may be directed to partnersupport@mykaarma.com.
